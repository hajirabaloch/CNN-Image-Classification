CNN Image Classification

Project Overview

This project uses a Convolutional Neural Network (CNN), a deep learning model, to classify images into six categories.

Classes

- Buildings
- Forest
- Glaciers
- Mountains
- Sea
- Streets

Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib
- Convolutional Neural Network (CNN)

Model Architecture

The CNN model uses convolutional layers to extract image features, ReLU activation to introduce non-linearity, max-pooling layers to reduce feature dimensions, and a dense classification layer with Softmax to predict the image class.

Dataset

The dataset contains images belonging to six classes: buildings, forest, glaciers, mountains, sea, and streets.

Results

The model achieved approximately 79.93% test accuracy.

How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Open the notebook or Python file.
4. Run the cells or script to train and evaluate the model.
